How to install

  1. Tap Download & install on your Android phone.
  2. Open the downloaded file (Reptivity.apk) from the notification or your Downloads.
  3. If Android asks, allow your browser to install unknown apps, then go back and tap Install.
  4. Updating? Do the same again. It installs over the old version and keeps you signed in.
If Play Protect warns you, tap More details → Install anyway. It shows this for any app that isn't from the Play Store yet.
